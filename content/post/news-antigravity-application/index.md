I have applied for **Google Antigravity** researcher access.

Antigravity is Google's agentic AI development environment. For the **Machine Psychology** work, I intend to use it to run larger-scale, automated red-teaming and interpretability experiments across LLMs — the kind of multi-turn behavioral probing that currently has to be scripted and managed by hand.

If the application is approved, I plan to publish the resulting datasets openly, as with all other work in this corpus.
